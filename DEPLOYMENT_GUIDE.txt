🚀 QUICKSTART - RUN LOCALLY (3 STEPS)
═══════════════════════════════════════════════════════════════════════════

OPTION 1: SIMPLEST (Just open in browser)
------------------------------------------
1. Double-click: veritascore_website.html
2. Opens in your browser
3. DONE! Website works immediately

The AI chat will use browser-based responses. To add REAL AI, see Option 2.


OPTION 2: WITH LOCAL AI (Ollama)
------------------------------------------
1. Install Ollama:
   • Go to: https://ollama.ai
   • Download for your OS (Mac/Windows/Linux)
   • Install it

2. Get an AI model:
   Open terminal/command prompt:
   
   ollama pull llama3
   
   (or try: mistral, phi, codellama, etc.)

3. Start Ollama:
   
   ollama serve
   
   Keep this terminal open

4. Open website:
   • Double-click veritascore_website.html
   • In the AI chat, select "Ollama" from dropdown
   • Start chatting with YOUR AI!

COMPLETELY FREE. COMPLETELY PRIVATE. RUNS ON YOUR COMPUTER.


OPTION 3: WITH PYTHON SERVER (Advanced)
------------------------------------------
1. Make sure Python is installed:
   
   python3 --version
   
   (If not installed, get from python.org)

2. Make server executable:
   
   chmod +x veritascore_server.py
   
3. Run the server:
   
   python3 veritascore_server.py
   
4. Open browser:
   • Go to: http://localhost:8000
   • Your website is now served locally!

METHOD 1: GitHub Pages (RECOMMENDED - Completely Free)
-------------------------------------------------------

STEP 1: Create GitHub Account
• Go to: https://github.com
• Sign up (free)

STEP 2: Create Repository
• Click "New Repository"

• Check "Add a README file"
• Click "Create repository"

STEP 3: Upload Your Website
• Click "Add file" → "Upload files"
• Drag and drop: veritascore_website.html
• Rename it to: index.html (important!)
• Click "Commit changes"

STEP 4: Enable GitHub Pages
• Go to Settings (in your repository)
• Scroll to "Pages" section
• Source: Deploy from a branch
• Branch: main
• Folder: / (root)
• Click Save

STEP 5: Access Your Website
• Wait 1-2 minutes
• Your site will be at: https://YOUR-USERNAME.github.io/veritascore

COST: $0 - Completely FREE forever!

🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

PROBLEM: Website won't open
SOLUTION: 
  • Make sure file is named index.html
  • Try different browser
  • Check file isn't corrupted

PROBLEM: Ollama AI not working
SOLUTION:
  • Make sure Ollama is installed
  • Run: ollama serve
  • Check it's running: http://localhost:11434
  • Try: ollama pull llama3

PROBLEM: GitHub Pages not showing site
SOLUTION:
  • Wait 5 minutes (can take time)
  • Check Settings → Pages is enabled
  • Make sure file is named index.html
  • Check repository is Public

PROBLEM: Custom domain not working
SOLUTION:
  • Wait 24-48 hours for DNS
  • Check domain DNS settings
  • Verify A record points to GitHub IP
