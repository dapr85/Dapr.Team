## 🔐 Key Features

### Cryptographic Integrity
First-to-market cryptographically verified self-modification. Every code change is signed, versioned, and auditable — meeting EU AI Act, FINRA, and HIPAA compliance requirements.

### Ultra-Lightweight Architecture
**6.8MB RAM footprint** enables deployment on edge devices, industrial PLCs, and tactical field equipment where competitors cannot operate.

### Air-Gapped Operation
Complete offline capability for classified environments, financial institutions, and sovereign AI deployments requiring data sovereignty.

### Versioned Rollback
Every modification is instantly reversible with cryptographic proof. Self-healing with automatic rollback on performance degradation.

### BYOLLM Architecture
**Bring Your Own LLM** — works with any local model (Ollama, LM Studio) or API. No vendor lock-in, 90%+ gross margins.

### Enterprise Ready
Built for regulated industries: defense, finance, healthcare, critical infrastructure. FedRAMP and SOC 2 compliance ready.

## 🚀 Quick Start

### Try the Live Demo
Visit [https://dapr85.github.io/Dapr.Team](https://dapr85.github.io/Dapr.Team) to:
- Explore the interactive AI chat
- See VeritasCore capabilities
- Test browser-based AI responses

### Connect Your Own Local AI
1. Install [Ollama](https://ollama.ai)
2. Download a model: `ollama pull llama3`
3. Start server: `ollama serve`
4. Select "Ollama" in the website dropdown
5. Chat with your private, local AI

### Deploy Your Own Instance
```bash
# Clone repository
git clone https://github.com/dapr85/Dapr.Team.git

# Open locally
open index.html

# Or serve with Python
python3 -m http.server 8000
```
